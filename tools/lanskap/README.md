# Pemanggang lanskap Aether Valley

Lanskap dasar dibuat dari 8 tileset SpriteCook di `sumber/` (t1 tanah, t2 tanah berbatu,
t3 rumput berbunga, t4 rumput kalem, t5 rumput rimbun, t6 rumput kering, t7 rumput dasar, t8 pasir).

1. `python3 kit.py`  -> ambil warna dasar, stempel detail, helai tepi; semua dipetakan ke palet 47
2. `python3 bake.py 11` -> panggang `lanskap_11.png` (1280x960 piksel seni = 40x30 petak @32)
3. salin hasil ke `assets/lanskap/lanskap_starter.png`

Folder ini diabaikan Godot (.gdignore) dan tidak ikut ke APK.
