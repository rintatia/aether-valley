# Aether Valley World Builder

## Open it
1. Open the Aether Valley project in Godot 4.7.2.
2. Open the main scene or a dedicated region scene.
3. Enable **Aether Valley World Builder** in Project > Project Settings > Plugins.
4. The dock appears on the left as **Aether World Builder**.

## Place an item
1. Choose a category.
2. Select an item to see its preview and source.
3. Keep **Create basic collision** enabled for solid objects; turn it off for crops and decorative objects.
4. Press **ADD ITEM TO OPEN SCENE**.
5. Select the new node in the Scene tree and move it in the 2D viewport. Use the Inspector to adjust properties.

The palette currently registers the initial integrated Spring Valley assets. It is an editor foundation, not a finished world editor: terrain painting, drag/drop placement, multi-tile brushes, seasonal variants, and expanded asset packs are subsequent implementation work. No tile dimensions are locked.
