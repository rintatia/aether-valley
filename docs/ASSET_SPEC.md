# Spesifikasi aset v7
- Format: PNG, latar transparan, satu objek per file (kecuali set ubin dan strip animasi).
- Skala: 1 piksel seni = 1 piksel gambar. Jangan diperbesar atau diperhalus.
- Ukuran dasar: petak 16x16, karakter sekitar 16x24.
- Palet: palet universal 47 warna (assets/palet/palet_47.txt). Tidak ada warna di luar palet.
- Nama: huruf kecil, garis bawah, tanpa spasi. Animasi: <nama>_<aksi>_<arah>_<jumlah>f.png, mis. petani_jalan_bawah_4f.png.
- Folder: karakter, tanaman, tanah, air, bangunan, objek, hud.
